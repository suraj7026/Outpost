# OP-017 — Usage, latency, and operational diagnostics

**Status:** Proposed · **Priority:** P1 · **Effort:** L · **Origin:** F17 + T3/Hermes
**Dependencies:** None for baseline instrumentation; align identifiers with OP-001 and OP-022.

## Problem and outcome
Live tool/message events do not explain queue wait, inference delay, context pressure, retry cost, or synchronization overhead. Instrumentation should precede claims that borrowed designs improve performance.

## Scope
Correlate task, run, input, tool action, model attempt, worker, and delivery IDs. Measure queue wait, first-token latency, execution duration, context usage, retry count, artifact bytes, stream snapshot/replay bytes, and reducer workload. Distinguish measured provider usage from estimates and unavailable billing data. Provide bounded per-run summaries and aggregate operational views with retention controls.

## Safety and recovery
Do not log full prompts, credentials, private reasoning, or tool payloads by default. Metrics emission must not block execution or create an unbounded buffer. Correlation metadata must respect identity/project visibility. Restarts should not double-count terminal runs or mislabel incomplete attempts as success.

## Acceptance criteria
- A deterministic test run yields traceable stage timings and outcome classification.
- Large-history/reconnect fixtures report transfer and processing costs before and after OP-018.
- Missing provider usage is shown as unknown/estimated, not zero-cost fact.
- Redaction and bounded-buffer tests pass under failed telemetry export.

## Extension-specific measurement
[OP-033](OP-033.md) adds Ollama account quota/request data and parent/child cost accounting; [OP-028](OP-028.md) supplies durable child receipts and [OP-030](OP-030.md) adds watchdog usage. Pi's ordinary session totals do not automatically include all async child usage. Aggregate by attempt identity, avoid double-counting nested totals, and expose missing evidence. Subscription balance, comparable per-token estimates, and measured task tokens remain separate fields.
