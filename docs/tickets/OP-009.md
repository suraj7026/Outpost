# OP-009 — Bounded specialist workers with aggregate budgets

**Status:** Proposed umbrella · **Priority:** P1 · **Effort:** XL across its slices · **Origin:** F09 + Hermes worker lanes + pi-subagents 0.83.0
**Dependencies:** OP-001, OP-007, OP-022; coding writers additionally require OP-019.

## Problem and outcome
Outpost has scope/budget inheritance, depth limits, leases, and cancellation primitives but not a complete live-worker lifecycle. Delegation should produce inspectable evidence, not unbounded hidden work.

## Scope
Add durable admission, parent/child lineage, lease ownership, heartbeat, cancellation propagation, result references, and terminal reconciliation. Require operator-authorized delegation or an explicitly approved workflow policy. Reserve aggregate parent budget before launching children and reconcile actual usage afterward; bound depth, concurrency, time, tokens, and effects. Use one writer per workspace. Parent verification decides whether a child result satisfies the task.

## Concrete extension-feature slices
The operator explicitly requested pi-subagents functionality, so this umbrella advances from P2 to P1. Implement it through [OP-026](OP-026.md) role profiles/preflight/model ceilings, [OP-028](OP-028.md) async lifecycle/fleet/retained runs, and [OP-029](OP-029.md) supervisor questions. Add [OP-027](OP-027.md) parallel workflows, review loops, and councils after those foundations; [OP-030](OP-030.md) adds opt-in watchdog review. These are implementation slices of the same worker system, not another runtime or duplicate effort estimates.

Unlike the extension's completed-child usage accounting, Outpost must reserve aggregate budget before concurrent admission. Child model selection and tool loadouts stay within server-enforced ceilings; ambient native tools/extensions must not bypass `outpost_action`. See the installed [workflow semantics](../../../../.pi/agent/npm/node_modules/pi-subagents/docs/workflows.md) and [launch-contract API](../../../../.pi/agent/npm/node_modules/pi-subagents/src/api/preflight.d.ts).

## Safety and recovery
Child authority is an intersection of parent scope and worker profile, never a union. Reject unknown worker identities rather than silently falling back. A lost worker receipt remains uncertain until reconciled. Hermes' current iteration counter is per-agent, despite older shared-budget descriptions; do not copy those weaker aggregate semantics. Environment lineage markers alone do not confine arbitrary subprocesses.

## Acceptance criteria
- Parallel children cannot collectively exceed reserved parent budgets.
- Parent cancellation/revocation stops admission and fences later effects.
- Restart reconciles each worker once without losing output provenance.
- A successful process exit without a validated result is not task completion.
