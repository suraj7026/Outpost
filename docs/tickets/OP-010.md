# OP-010 — Resumable deterministic recipes

**Status:** Proposed · **Priority:** P2 · **Effort:** L · **Origin:** F10 + Hermes script-only jobs
**Dependencies:** OP-001, OP-022; OP-004 for scheduled invocation, OP-008 for connector-backed steps.

## Problem and outcome
Outpost can validate workflow dependencies and artifact-backed evidence but lacks a complete resumable runner. Repeated procedures should not need a fresh model to rediscover every deterministic step.

## Scope
Define versioned recipes with typed inputs, dependency graph, step actions, outputs, preconditions, verification, and explicit approval boundaries. Persist per-step attempts and receipts; resume from proven completion rather than replaying the entire graph. Support deterministic probes and report transformations before adding external mutations. Allow a recipe to run with no model when all steps are deterministic. Show the plan, current step, blocked reason, and resulting artifacts.

## Safety and recovery
Approval is tied to resolved arguments and recipe revision, not a blanket “run workflow” permission. Classify steps as retry-safe, reconcile-required, or non-repeatable. Unknown side effects block downstream work. Compensation is a separately authorized action, not guaranteed rollback. Reject inline scripts supplied by untrusted events; executable recipe content must be reviewed and pinned.

## Acceptance criteria
- A crash after step completion resumes without duplicate effects.
- Changed inputs or recipe revision invalidate stale approvals.
- Dependency cycles and missing artifacts fail before dispatch.
- Cancellation prevents new steps while retaining auditable completed output.

## Delegation workflow boundary
[OP-027](OP-027.md) adds agent orchestration, review loops, and councils using pi-subagents patterns. This ticket remains owner of deterministic host steps, resolved-action approval, step receipts, and retry/reconciliation semantics. A workflow may compose both, but script/template selection is not blanket command authority. [Named workflow resources and typed gates](../../../../.pi/agent/npm/node_modules/pi-subagents/docs/workflows.md) are useful references; arbitrary model-authored scripts do not gain host execution privileges.
