# Outpost / Graphite studies

Approved scope: three interactive browser mocks, not changes to the shipping Tauri client. All tasks, approvals, timestamps, machine results and files are illustrative. No live API, identity, approval or execution access.

## Three compositions

- Graphite Studio: labelled sidebar, rounded inset workspace, conversation with a persistent evidence inspector. The execution path becomes a vertical handoff spine. Most comfortable for everyday review.
- Ink Precision: horizontal navigation, compact task queue, execution ledger and adjacent patch. A timestamped run strip makes the causal chain legible. Tight corners and neutral underline selection. Best for investigating work.
- Quiet Workspace: top navigation, centered open reading plane, an inline evidence fold and bottom task shelf. The agent-to-human handoff becomes a horizontal progress ribbon. Most focused, with evidence one action away.

Studio/Quiet retain lightness-only panel separation; Precision uses rules and underline selection.

## Interactive prototype

Design selector, comparison overview, light/dark preview, motion on/off, replayable inspection sequence, task switching, inspector tabs, expandable evidence, exact-action dialog with simulate approval and undo, local follow-up messages, sample-task dialog and keyboard shortcuts. One active simulation timer is cancellable; design changes preserve each task's state. Controls never send network requests.

Motion: 140ms press feedback; 220ms tab/selection movement; 280ms evidence/dialog disclosure; 360ms design crossfade; finite, replayable inspection path drawing; completion check stroke; task progress transitions. No endless ambient animation. Reduced motion cancels travel and all custom animations; information remains visible.
